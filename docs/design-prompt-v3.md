## §0 使用说明（先读，关乎 Token / 对话长度）

Claude Design 会把整段对话 + 生成的 HTML 都留在上下文，长对话 + 大文件会撑爆、变慢、质量倒退。请遵守：

1. **一屏一条消息**。先发一次 §1「设计系统」当作置顶基准，之后每屏（§2 里每个编号）**单独一条消息**，每条只说该屏，引用「沿用已确立的设计系统」，不要重复长描述。
2. **每屏单独导出一个 `.dc.html`**。
3. **一律扁平 SVG + CSS，禁止内嵌位图 / base64 图片**（文件要小、省 token，也更贴纪念碑谷扁平风）。
4. 对话变慢/报错时**新开一个会话**，只把 §1 重贴一次，再继续没做完的屏。
5. **不要把旧的大 `.dc.html` 贴回**；需要视觉参考时，用我另外给的 2 张游戏截图（主菜单 + 游戏内）即可。
6. 交付顺序建议按 §2 的编号；1–3 是最高优先（玩法核心视觉），4–6 次之。

## §1 设计系统（置顶 · 每个新会话先发这段）

```
项目：《向上之塔 Upward》——2D 侧视「禅跳」攀爬。视觉：纪念碑谷式扁平几何 + 冷→暖希望叙事。
主题：放下，越轻越高。角色背负「负累」（3–4 个半抽象小几何暗影），每一次“正心落点”卸下一分负累 →
      变轻 → 跳得更高更飘。爬升 = 卸载 = 解脱。五座塔 = 五重放下（恐惧/执着/喧嚣/自我/名相）。

基调：孤独、静谧、向上、逐渐升起的希望。无血条、无分数、无弹窗。极简、留白、柔和长投影、飘浮光尘。
字体：标题 Cormorant Garamond；数字/正文 Inter。
色板：奶白 #fffcf5 / 深夜蓝黑 #06070a·#1b2330 / 暖金 #e8b86d / 雾蓝 #6b8cae / 暖桃 #f2c49b。
五塔色温（冷→暖，顶端最暖）：
  晨雾塔 #6b8cae · 生活国度 #7e9a94 · 云海齿轮 #a89170 · 仙山天梯 #d0a860 · 逆位之塔 #e0b878
执行铁律：扁平 SVG + CSS，禁位图；平台=顶面高光+厚度暗面+柔和长投影；机关靠形状差异一眼可辨，不靠文字。
```

## §2 逐屏请求（每个编号单独一条消息发送）

### 1. 角色 · 轻重形态谱（最高优先，本作视觉灵魂）
沿用设计系统。画同一个攀登者剪影的 **4 个轻盈阶段**，横排对比：
- **重（w≈0.9）**：剪影深实、体量沉，身后跟着 3–4 个半抽象小几何暗影（负累）。
- **渐轻（w≈0.6 / 0.3）**：暗影逐个脱离；剪影开始透光、边缘生出微光。
- **轻（w≈0）**：通体发光、生出柔和光晕、拖着一缕流光，近乎纯光。
另附一张 **「卸下负累」瞬间**：一个暗影脱离、下坠、化为光点飘散，旁边一句短诗（Cormorant Garamond，淡入）示例「放下山影」。

### 2. 游戏内 HUD（极简 · 横屏）
沿用设计系统。叠在游戏画面上，元素尽量少：
- 左上：**海拔数字**（Inter，上升时高亮）。
- 右边缘：**海拔刻度尺 + 游标**。
- **轻盈度**：不用数字、不用血条——用**角色自身的辉光强度 / 拖尾长度**表达（给出"重/轻"两态示意）。
- **蓄力 + 弹道预览**：底部**蓄力条** + 一条**金色虚线抛物弧线**指向落点（精致化，这是核心操作 UI）。
- **正心落点反馈**：落在平台**中心甜区**时的一圈**光晕扩散 + 一次微光脉冲**（无文字、无数字；连击用光的累积表达，不用计数）。
给「蓄力瞄准中」和「正心落点命中」两张关键帧。

### 3. 「放下之路」升级树（成长星图）
沿用设计系统。三分支按色温区分，**只做容错 / 探索 / 外观，绝不加跳跃力/二段跳/降重力**：
- **从容之路** #6b8cae（冷）：甜区更大、下沉更柔、变重更慢、多一次歇脚。
- **明心之路** #e8b86d（暖）：显现捷径、解锁风景、明心（原星核）指引。
- **表达之路** #8b7fa8（紫）：光之形态皮肤、拖尾、卸负累特效。
节点发光三态（已点亮/可点亮/锁定）+ 连线 + hover 说明卡（名称/效果/光点消耗）；顶部显示光点余额。

### 4. 机关视觉语言（一屏内画全套小样）
沿用设计系统。给每种机关一个**一眼可辨**的扁平样式：
- **正念踏石**：落上即开始消隐，唯有正心落点能多停留（画"实/半隐"两态）。
- **上升气流（御风）**：轻则被托起——用柔和上升流线暗示，仅在"轻"态生效。
- **呼吸平台**：随缓慢呼吸涨缩，吸气顶点 = 正心（画大/小两态）。
- **尘缘重物**：悬着的执念之物，拾取=捷径但加重（要有"诱惑又危险"的暗示）。
- **杂念飘尘**：温柔漂浮的念头，碰到微微加重（非敌人，柔和）。

### 5. 解脱 · 通关画面
沿用设计系统。在既有通关画面基础上进化为**"卸尽负累、通体透光、世界点亮"**：镜头拉远、暖光漫开；
居中展示 用时 / 坠落 / 海拔 / 明心；一句收束短诗；入口 再次攀登 / 返回。用该塔暖色调点题。

### 6. 主菜单 & 地图选择（在现有版本上提升）
沿用设计系统。
- 主菜单：远景剪影塔 + 标题 + 开始攀登 / 选择地图 / 设置；副标题「雾起之处，唯有向上」。
- 地图选择：五张塔卡片横排，体现「五重放下」与冷→暖色温；未解锁显示剪影 + 锁 + 解锁条件 + 该塔"放下"主题名。
