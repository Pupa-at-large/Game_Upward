# 玩法设计 · 禅跳 × 放下越轻越高（已对齐）

> 核心玩法与主题的设计基准。实现以此为准，`tuning.ts` 承接可调数值。

## 一句话

蓄力精准跳 + 完美落点连击（禅跳）。**「轻盈度」是核心变量**：正心落点 = 放下一分负累 → 变轻 → 跳得更高更飘。**机制即叙事**（放下，越轻越高）。

## 核心循环

1. 站台上按住蓄力，金色弹道预览显示落点（受重量影响：重则弧线平而短）。
2. 松手起跳，落到下一台：
   - **正心**（中心甜区）：连击+1，卸下一缕负累 → 变轻；光晕 + 上行音符。
   - **稳**（台上偏心）：站稳，连击保持，不减重。
   - **失**（没够到）：**柔性下沉**到上一歇脚 + 略加重，连击断；绝不硬重开。
3. 每若干正心 / 每里程碑：一件负累脱落化光 + 一句放下短诗 + 世界暖一档。
4. 登顶 = 卸尽负累、通体透光、世界全暖 = 解脱。

## 重量物理（越轻越高是真的）

- `w`（负累）∈ [0,1]，进塔较重（~0.9），随正心降到该塔下限。
- `有效重力 = 基础重力 × (0.55 + 0.45·w)`。
- 同样蓄力，`w` 越低跳得越高越远；`w` 低时弧顶有轻微悬停、下落封顶更慢（飘落）。
- 每座塔重置负累（新的放下之旅）；塔内有下限，不会无限轻。

## 锁定的细节

1. **甜区**：恒定 ±35% 台宽，基础宽容；更高容错走「放下之路」升级。
2. **失败**：柔性下沉到上一歇脚 + 略加重；仅整段跌出多沉一档；永不硬重开。
3. **首个切片**：核心循环 + 重量物理 + 正心连击 + 柔性下沉 + 正念踏石 + 上升气流，晨雾塔（放下·恐惧）。
4. **负累具象**：3–4 个半抽象小几何暗影跟随，卸下时化光。

## 机关（围绕 禅 / 放下 重铸）

- **正念踏石**：落上即消隐，唯正心落点多停留（奖励专注）。
- **上升气流**：轻则被托起，重则托不动（轻盈解锁浮升）。
- **呼吸平台**：随呼吸涨缩，吸气顶点 = 正心。
- **尘缘重物**：拾取给捷径但加重（抉择：要快还是要轻）。
- **杂念飘尘**：碰到微微加重（非敌人，穿行其间保持清明）。

## 主题三层

- **叙事**：负累逐件卸下、化光 + 放下短诗；五塔 = 五重放下（恐惧/执着/喧嚣/自我/名相）。
- **视觉**：角色由深实拖影 → 通体透光生晕拖流光；叠加冷→暖黎明。
- **听觉**：生成式环境音，正心落点添音符，音高随连击上行（玩得越顺，乐越完整）。

## 复用与重映射

- 复用：纪念碑谷渲染、冷→暖主题、金色弹道预览、飘浮光尘、区段结构、存档、菜单/选图/通关。
- **星核 → 明心**：可选收集，给一小簇轻盈。
- **升级树 / 光点 → 放下之路**：全是容错/从容/探索/外观类，绝不加跳跃力/二段跳/降重力。

## "怪"如何消解

旧的"弹跳后要再按方向"来自离散跳 + 弱空中控制 + 弹簧只给垂直力。禅跳里瞄准在松手前定死、弧线即承诺、
不做空中乱操作 → 该问题被设计消解，多半不必单独修。
