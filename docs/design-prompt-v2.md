# 给 Claude Design 的 UI 设计 Prompt · v2（2D · 纪念碑谷风）

> 直接把下面整段发给设计师会话。这是在你已有那版「深色电影感 + 冷雾/暖金 + Cormorant Garamond」基础上的**风格迭代**：从 3D 改为 **2D 侧视攀爬**，整体美术转向**纪念碑谷（Monument Valley）的扁平几何 + 柔和暖调**，并保留「越往上越暖」的色温叙事。

---

## 整体基调（锁定）

- **游戏类型**：2D 侧视「蓄力跳爬塔」（Only Up / Jump King 那类玩法），但视觉是**纪念碑谷式的扁平几何**——不是写实，是干净的色块、克制的留白、柔和的长投影、淡淡的等距厚度感。
- **核心情绪**：孤独、静谧、向上、逐渐升起的希望。无血条、无分数、无弹窗。
- **色温叙事**：5 座塔从**冷雾蓝灰 → 暖金晨曦**线性过渡。越往上爬，世界越暖、越亮、越有希望。
- **字体**：标题用 **Cormorant Garamond**（衬线，优雅）；UI 数字/正文用 **Inter**。
- **基础色板**（沿用你上一版提取值）：奶白 `#fffcf5`、深夜蓝黑 `#06070a / #1b1d22`、暖金 `#e8b86d`、雾蓝 `#6b8cae`、暖桃 `#f2c49b`。
- **几何语言**：平台 = 带顶面高光 + 一侧厚度暗面 + 柔和长投影的几何块；可点缀「不可能建筑」的小母题（错位楼梯、悬浮拱、镜像）。飘浮光尘营造空气感。

## 输出要求

每个界面导出为**自包含 `.dc.html`**，可交互。除特别说明外，**HUD/游戏内为横屏**（2D 侧视需要横向空间），菜单类竖屏/横屏皆可。

---

## A. 通用界面（5 屏）

### A1. 主菜单
- 竖向构图：远景是一座**扁平几何剪影塔**，自下而上由冷转暖，顶端一缕暖光。
- 标题「向上之塔 / UPWARD」用 Cormorant Garamond，居中或左对齐。
- 三个文字入口：**开始攀登 / 选择地图 / 设置**（hover 有微光位移）。
- 副标题一句：「雾起之处，唯有向上」。

### A2. 游戏内 HUD（横屏，2D 侧视）
- 极简，叠在游戏画面上：
  - **左上**：当前海拔数字（Inter，上升时高亮），单位 m。
  - **右边缘**：竖向**海拔刻度尺** + 当前高度游标（沿用你上版 1b 的海拔尺）。
  - **底部居中**：**蓄力条**——仅按住蓄力时出现，从弱到满有暖色推进。蓄力跳是核心，蓄力条要好看、读数清晰。
  - **坠落反馈**：屏幕边缘**泛红 + 轻微失焦**，无文字。
- 给出一个「蓄力中」状态和一个「正常攀爬」状态两张图。

### A3. 地图选择（横向卡片轮播）
- 5 张塔卡片横向排布，当前居中放大、左右半隐。
- 每卡：塔名 + 一句 tagline + **扁平几何塔缩略图**（体现该塔色温）+ 最佳记录占位（最高海拔 / 最佳用时）。
- 未解锁卡：剪影 + 锁 + 解锁条件文字。
- 卡片色温对应下方 5 座塔。

### A4. 升级树（成长之树 / 星图）
- 三分支按色温区分：**旅者之路** `#6b8cae`（冷）/ **探索之路** `#e8b86d`（暖）/ **表达之路** `#8b7fa8`（紫）。
- 节点为发光星点，三态：已点亮 / 可点亮 / 锁定；分支间连线。
- 节点 hover 弹说明卡：名称 + 效果 + 消耗光点。顶部显示光点余额。
- **红线**：只做容错 / 探索 / 外观类，**绝不出现二段跳、降重力、加跳跃力**等破坏核心挑战的字样。

### A5. 通关画面
- 镜头拉远、整座塔被点亮的氛围；顶部用该塔暖色调点题。
- 居中三项数据：**用时 / 坠落次数 / 到达海拔**。
- 两个入口：**再次攀登 / 返回**。

## B. 五座塔 · 逐关美术 + 机关（重点）

> 每关给：①一张「封面 / intro」竖屏稿；②一组「游戏内场景」横屏稿（体现平台几何、背景母题、机关样式、色温）。机关样式要可辨识——玩家一眼能读懂这块平台会动 / 会消失 / 会弹。

### 1. 晨雾塔 misty-tower（教学 · 最冷）
- **色温**：冷雾蓝灰起点。天空 `#2a3340`（底）→ `#6b8cae`（顶），平台奶灰 `#cdd3da`，暖金游标 `#e8b86d`。
- **氛围**：浓雾、孤塔、万籁俱寂。雾从底部漫起，越往上雾越薄、透出一点天光。
- **几何母题**：朴素的方台、断桥、雾中若隐若现的拱。大量留白。
- **机关**：`static` 静态台 / `moving` 横向往复台（雾中缓缓平移）/ 基础**抓握边缘**（边缘要有可读的「可抓」视觉提示，如一道高光唇线）。
- **一句**：「雾起之处，唯有向上。」

### 2. 生活国度 living-realm（渗暖青瓷）
- **色温**：雾退去，渗入暖意。青瓷绿灰 + 暖木色。天空偏暖灰，平台带一点奶油暖。
- **氛围**：把「生活物件」抽象成巨大的几何积木——书本、台灯、抽屉、织物。温馨、治愈，像走进一间被放大的房间。
- **几何母题**：堆叠的**书本台阶**、悬浮的抽屉、布幔吊桥。
- **机关**：`bouncer` 弹簧（抽象成压缩的弹簧 / 蹦床，给额外垂直力，要有蓄势感）/ `moving` 书本传送（横向移动的书）/ `fading` 踩上后渐隐的脆弱台（如薄纸 / 玻璃，渐隐过程要可读）。
- **一句**：「平凡之物，皆可为阶。」

### 3. 云海齿轮 cloud-gears（中性暮色 · 黄铜）
- **色温**：中性偏暖的暮色，黄铜 + 锈橙 + 云白。第一次出现明显金属暖光。
- **氛围**：穿出云海，进入一座**机械塔**。巨大齿轮缓缓咬合，蒸汽与云雾交织，暮色给金属镀上暖边。
- **几何母题**：旋转齿轮、传送带、错位的管道与拱（适合放纪念碑谷式「不可能咬合」的母题）。
- **机关**：`gear` 旋转齿轮（需踩在齿上随之转动，齿的间距要可读）/ `wind` 风力区（持续横向推力，用飘动的云絮 / 线条暗示风向）/ `moving` 传送带（横向恒速带动）。
- **一句**：「锈蚀的齿轮，仍向高处转。」

### 4. 仙山天梯 celestial-stairs（暖金夕照）
- **色温**：暖金夕照，霞光满天。最接近「希望」的暖。
- **氛围**：东方仙山，云上天梯。悬浮的踏石、御风的飞檐、点点灯笼。空灵、辽阔、金光流动。
- **几何母题**：螺旋上升的**天梯**、悬浮飞檐、镜面般的云海倒影（可玩纪念碑谷镜像母题）。
- **机关**：`fading` 消失踏石（点状悬浮石，踩上即开始消逝，逼迫节奏）/ `wind` 御风（强上升 / 横向气流，用霞光流线表现）/ `bouncer` 灯笼（撞上给弹力的发光灯笼）。
- **一句**：「踏云而上，霞光为梯。」

### 5. 逆位之塔 inverted-tower（晨曦暖金 · 顶点最暖 · 终局）
- **色温**：晨曦暖金，全局最暖最亮，但带一丝诡谲的高对比——这是终极试炼。
- **氛围**：**重力翻转 / 镜像 / 限时坍塌**。一座违反直觉的塔，上下颠倒、左右成镜，结构在你脚下崩解。纪念碑谷「不可能建筑」在这里推到极致。
- **几何母题**：上下镜像的双塔、旋转 90° 的重力区、正在崩裂的拱与阶。
- **机关**：**重力翻转区**（进入后上下颠倒，背景与投影方向同步翻转，要让玩家一眼看懂当前重力朝向）/ **镜像区**（左右操作反转，用对称构图暗示）/ **限时坍塌**（强化版 fading，整片结构按序崩塌）。
- **解锁**：集齐前四座塔全部星核。
- **一句**：「颠倒众生，顶点见光。」

## C. 关键视觉细节（统一执行）

- **平台**：顶面亮色 + 朝光侧高光唇线 + 背光侧厚度暗面 + 一道**柔和长投影**，营造纪念碑谷的几何体量感。可动/消失/弹跳机关用**形状或图标差异**让玩家一眼区分，不靠文字。
- **角色**：一个**小而精致**的攀登者剪影（参考纪念碑谷艾达的比例——小、纯净、有一点暖/冷的轮廓光）。蓄力时有下蹲蓄势的姿态。
- **空气感**：飘浮光尘 / 雾 / 云絮随高度变化；越往上颗粒越暖越亮。
- **星核 / 光点**：暖金发光多面体，是全局唯一的强暖点，冷关里尤其要跳出来。

> 纪律重申：HUD 无血条、无分数、无弹窗；坠落只用屏幕边缘泛红 + 轻微失焦表达，无文字。升级只影响容错 / 探索 / 外观，永不触碰核心跳跃挑战。
